# Auth Drawer Lab

Auth drawer and modal playground by Remco Stoeten.

This project is a Vite/React lab for testing an authentication surface across:

- email/password sign-in and registration
- OAuth provider buttons, or no OAuth at all
- modal and drawer variants
- auth flow and backdrop visual config
- validation, backend, network, rate-limit, and OAuth error states
- light and dark themes

Run locally:

```sh
bun install
bun run dev
```

Build:

```sh
bun run build
```
